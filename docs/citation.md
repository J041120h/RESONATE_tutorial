# Citation

If you use RESONATE, please cite the paper:

> Jiang, H., Ji, H. & Chitra, U. Predicting unmeasured features in spatial omics with single-cell references and gene
> embeddings. Manuscript in preparation (2026).

A BibTeX entry and the DOI will be added here when the preprint is posted. The software itself can be cited from the
code repository's `CITATION.cff` file (GitHub shows it under "Cite this repository").

## Data and models used by the tutorials

If you use the demo data or the default gene embeddings, please also cite:

* **Fetal heart MERFISH data and scRNA-seq reference.** Farah, E. N. *et al.* Spatially organized cellular communities
  form the developing human heart. *Nature* 627, 854–864 (2024).
  [doi:10.1038/s41586-024-07171-z](https://doi.org/10.1038/s41586-024-07171-z). Data: Dryad
  [doi:10.5061/dryad.w0vt4b8vp](https://doi.org/10.5061/dryad.w0vt4b8vp) (CC0 1.0).
* **scGPT-spatial gene embeddings.** Wang, C. *et al.* scGPT-spatial: continual pretraining of single-cell foundation
  model for spatial transcriptomics. *bioRxiv* (2025).
  [doi:10.1101/2025.02.05.636714](https://doi.org/10.1101/2025.02.05.636714). Weights: figshare
  [doi:10.6084/m9.figshare.28356068](https://doi.org/10.6084/m9.figshare.28356068) (CC BY 4.0).
